Title:
User can successfully create account with valid credentials.
Steps:
1. Navigate to account creation page at:
https://magento.softwaretestingboard.com/customer/account/create/
2. Enter data for all fields:
First Name: test
Last Name: test
Email: test@gmail.com
Password: test1234
Confirm Password: test1234
Expected result:
User is navigated to its profile and success message is displayed.
